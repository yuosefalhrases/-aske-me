# aske me

AI-powered study quiz MVP.

Flow:
Upload study material → extract text → AI generates validated MCQs → take quiz → review explanations and sources.

Current supported document formats:
- PDF
- DOCX
- PPTX

Important:
- Keep the real OpenAI API key in the hosting provider's environment variables.
- Never commit `.env` or a real API key to GitHub.
- This is an MVP; production authentication, rate limits, database, analytics, OCR/images, and stronger security still need to be added.
